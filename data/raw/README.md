# Raw data (not included)

This analysis uses data from the **National Health and Aging Trends Study
(NHATS)**, including the wrist-worn accelerometry substudy (Rounds 11–14,
2021–2024). **The raw data are not redistributed in this repository** because
they are governed by the NHATS Data Use Agreement.

## How to obtain the data
1. Download the NHATS Sensitive and public-use files for Rounds 11–14 from
   <https://nhats.org/> (registration / data-use agreement required).
2. Obtain the accelerometry substudy files and process the raw tri-axial
   signals with the OxWearables **stepcount** pipeline
   (<https://github.com/OxWearables/stepcount>) to derive the daily-level
   metrics (daily steps, walking minutes, peak 30-min cadence, etc.).
3. Merge the derived accelerometry metrics with the NHATS core interview
   variables into a single person-wave file named **`df.csv`** and place it here:

   ```
   data/raw/df.csv
   ```

## Expected columns (subset actually used by the pipeline)
`id, wave, age, sex, accelerometer, weights_nhats,`
`Steps_ponderada, Walk_mins_ponderada, CadencePeak30_steps_min_ponderada,`
`CadencePeak1_steps_min_ponderada, Cadence95th_steps_min_ponderada,`
`sisindex, res, income, frailty_category, bmi, mort_status`

- `accelerometer == 1` flags valid accelerometry person-waves.
- `*_ponderada` = wave-level averages weighted across valid wear days.
- `weights_nhats` = NHATS analytic (expansion) weight for the round.
  Note: stratum / primary-sampling-unit variance variables are **not** part of
  this file, so design-based (Taylor-linearised) variance estimation is not
  performed (see the manuscript, Statistical analysis).

## Don't have the data yet?
A tiny **synthetic** sample is provided so the pipeline runs end-to-end:
`data/synthetic/df_synthetic.csv` (generated by `data/synthetic/make_synthetic.R`).
Its values are random and **do not reproduce** the published estimates.
